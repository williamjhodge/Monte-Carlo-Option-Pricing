# Monte-Carlo-Option-Pricing

## Overview

This project implements a Monte Carlo simulation to price European call options under the Black–Scholes model.

## Methods

- Geometric Brownian motion
- Monte Carlo simulation
- Black–Scholes analytical pricing
- Convergence analysis
- Numerical differentiation
- Antithetic variates

## Results

The Monte Carlo estimator was compared with the analytical Black–Scholes price.

The experimentally estimated convergence rate was **−0.504**, which is close to the theoretical **−0.5** expected for Monte Carlo methods.
